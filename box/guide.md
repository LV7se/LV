# 使用说明

LV Box 在浏览器里直接与手机通信，不需要安装客户端。

## 前提

- 支持 WebUSB 的 Chrome、Edge 等 Chromium 内核浏览器
- 手机开启开发者选项与 USB 调试，使用可传输数据的 USB 线
- 通过 HTTPS 或 `localhost` 打开本站

## 连接

点击「选择设备」，在弹出的系统窗口中选中手机，然后允许调试授权。首次连接会在浏览器中生成一对密钥，之后同一台电脑可直接复用。

## 边界

功能是否生效取决于设备的 Android 版本、厂商 ROM 与 ADB Shell 权限。部分系统信息在受限设备上读不到；进入 Fastboot 的操作只发送重启命令，不提供刷机。

::: warning 提醒
玩机操作有风险，请确认了解每一步的后果再执行。
:::
