## 打开就能用

不需要安装客户端，也不用在本机配置 ADB 环境。连接数据线，打开网页，剩下的在页面里完成。

## 前提不复杂

支持 WebUSB 的 Chromium 内核浏览器，手机开启 USB 调试，通过 `localhost` 或 HTTPS 访问。

## 边界说清楚

能做什么、在什么设备上做不到，页面上直接写明，不靠一句「全机型支持」带过。
