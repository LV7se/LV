# 关于

## 项目简介

**LV Box 是《搞机工具箱》网页版**。《搞机工具箱》是一款 ADB 图形化工具，网页版则是把它从桌面端搬到浏览器里的移植版本 —— 同一套操作思路，换了一个运行环境，省掉了下载与安装。

它运行在基于 Chromium 内核的浏览器中，通过 USB 连接手机，在网页里完成常见的玩机操作。页面上的功能是否生效，取决于设备的 Android 版本、厂商 ROM 以及 ADB Shell 的权限。

## 项目背景

原版《搞机工具箱》是个人开发的 PC 软件。把它做成网页版，起点很实际：PC 版需要下载、安装、处理运行环境，换台电脑就要重来；而网页只要打开一个地址就能用，也不挑操作系统。

实现上，网页版借助 [Tango](https://github.com/yume-chan/ya-webadb) 提供 WebADB 能力，通过 [xterm.js](https://github.com/xtermjs/xterm.js) 打通 Android 原生 Shell 的交互式终端。两者都是在浏览器里模拟原本由本地 ADB 客户端承担的职责，这也是「免安装」能够成立的前提。

## 我们怎么想

**把复杂度放到实现里，不要放到使用上。** 用户打开的应该是一个网页，而不是一份安装说明。

**信息要如实。** 支持哪些浏览器、需要开启什么、哪些信息读不到、哪些操作有风险，都直接写在页面上。做不到的事情不承诺，限制条件不藏在角落。

**依赖尽量少。** 页面与第三方组件随站点一起提供，不需要访问者额外构建或安装依赖；部署到静态托管之后，访问者侧不需要 Node.js。

**边界要说清楚。** 这个工具面向有一定玩机基础的人。进入 Fastboot 的按钮只发送重启命令，不提供刷机功能；工具不会替使用者判断操作后果。

## 使用前提

- 使用支持 WebUSB 的 Chrome、Edge 或其他 Chromium 内核浏览器（手机安装 Chrome 同样可用）
- 手机开启开发者选项与 USB 调试，使用支持数据传输的 USB 线连接
- 通过 `localhost` / `127.0.0.1` 或 HTTPS 站点访问页面
- Windows 需要能正常识别手机的 ADB USB 接口，并在手机端同意授权请求

## 数据与连接

- **连接链路**：设备命令通过浏览器与手机之间的 USB 连接执行，不经过任何远程 ADB 服务。
- **本地存储**：设置、脚本文本、操作记录保存在当前网站的浏览器本地存储中；清理网站数据会删除这些内容。
- **ADB 身份密钥**：由 Tango 保存在浏览器的 IndexedDB 中，可在断开设备后通过软件设置清除。
- **地址变化**：不同协议、域名或端口使用独立的网站存储，迁移部署地址后可能需要重新授权。
- **临时数据**：截图、电池统计等需要及时下载保存，页面内的临时数据不会跨刷新保留。
