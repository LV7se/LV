# 关于

LV Box 是《搞机工具箱》的网页版 —— 一款在浏览器中运行的 ADB 图形化工具。

桌面版需要下载、安装、配置环境，换一台电脑就要重来一次。LV Box 把这一步去掉：连上数据线、打开网页，就可以操作设备。它也不挑操作系统，只要浏览器支持 WebUSB，Windows、Linux、macOS 都能用。

## 使用前提

- 支持 WebUSB 的 Chromium 内核浏览器
- 手机开启开发者选项与 USB 调试，使用可传输数据的 USB 线
- 通过 `localhost` / `127.0.0.1` 或 HTTPS 页面访问

## 边界

功能是否生效取决于设备的 Android 版本、厂商 ROM 与 ADB Shell 权限，部分系统信息在受限设备上读不到。进入 Fastboot 的操作只发送重启命令，不提供刷机。

设备与网页之间通过 USB 直接通信，不经过远程 ADB 服务；设置与操作记录保存在当前网站的浏览器本地存储中，清理站点数据会一并删除。

::: warning 提醒
玩机操作有风险，请确认了解每一步的后果再执行。
:::
