# 关于

## 项目简介

**LV Box 是《搞机工具箱》网页版**，一款 ADB 图形化工具。桌面版需要下载安装、配置环境，网页版把这一步省掉，打开网址就能用。功能是否生效，取决于设备的 Android 版本、厂商 ROM 与 ADB Shell 权限。

## 项目背景

原版《搞机工具箱》是个人开发的 PC 软件，做成网页版是为了免安装、跨平台。实现上借助 Tango（ya-webadb）提供 WebADB 能力，用 xterm.js 提供 Shell 终端，在浏览器里承担本地 ADB 客户端的工作。

## 我们怎么想

- **复杂度放在实现里。** 用户打开的应该是一个网页，不是一份安装说明。
- **信息如实。** 支持哪些浏览器、需要开启什么、哪些读不到、哪些有风险，都直接写在页面上。
- **依赖尽量少。** 页面与组件随站点提供，访问者不需要构建或安装依赖。
- **边界说清楚。** Fastboot 按钮只发送重启命令，不提供刷机。

## 使用前提

- 支持 WebUSB 的 Chrome、Edge 等 Chromium 内核浏览器（手机 Chrome 同样可用）
- 手机开启开发者选项与 USB 调试，使用可传输数据的 USB 线
- 通过 `localhost` / `127.0.0.1` 或 HTTPS 访问页面
- Windows 需能识别手机的 ADB USB 接口，并在手机端同意授权

## 数据与连接

- **连接链路**：命令经浏览器与手机的 USB 连接执行，不经过远程 ADB 服务。
- **本地存储**：设置、脚本、操作记录存在浏览器本地，清理站点数据会一并删除。
- **ADB 密钥**：由 Tango 保存在浏览器 IndexedDB 中，可随时清除。
- **临时数据**：截图、电池统计需要及时下载，不会跨刷新保留。
